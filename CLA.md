# TARHAN Contributor License Agreement (CLA)

**Version 1.0 — 2026-07-31**

Thank you for contributing to TARHAN. Please read this before your first pull
request. It is short, and we explain plainly why it exists.

## Why this exists

TARHAN is released under the **AGPL-3.0-or-later**. Some users cannot accept AGPL
terms — for example, embedding TARHAN in a closed-source product, or running a
modified version as a network service without publishing their source. For those
users a **separate commercial license** is offered.

Offering a commercial license is only legally possible if one party holds the
right to license the whole codebase under those other terms. If contributions
arrived with no such grant, that would become impossible, permanently — every
past contributor would have to be found and asked to agree.

This agreement solves that. **It is not a copyright assignment: you keep the
copyright to everything you write.** You grant a license broad enough that the
project can continue to be offered under both AGPL and commercial terms.

## How to sign

In the description of Your first pull request, include this line:

```
I have read the CLA.md document and I hereby sign the CLA.
```

Your GitHub username and the pull request record serve as the signature. You only
need to do this once; it covers all Your future Contributions to this project.

If You are contributing on behalf of an employer or other legal entity, please
say so in the same pull request so a corporate agreement can be arranged.
